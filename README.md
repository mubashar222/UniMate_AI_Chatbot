# 🎓 UniMate AI — Local University Chatbot

A professional university-project chatbot built with **Streamlit + Ollama + Llama 3.2**.

## What makes it an actual AI chatbot?

The response is generated by a local LLM through Ollama. It is not a fixed FAQ/rule-based bot.

**Architecture:**

Streamlit UI → Python → Ollama Local API → Llama 3.2 → AI Response

No OpenAI/Gemini API key is required.

## Requirements

- Windows 10 or later
- Python 3.10+ recommended
- Ollama for Windows
- Around 2 GB free disk space for the default 3B model, plus some extra working space

Ollama provides a local API on `http://localhost:11434`. Llama 3.2 has 1B and 3B local variants; the default 3B model is about 2 GB in Ollama's library.

## STEP 1 — Install Ollama

Download Ollama for Windows from the official website:

https://ollama.com/download/windows

Install it normally.

After installation, open PowerShell and check:

```powershell
ollama --version
```

## STEP 2 — Download the AI model

Run:

```powershell
ollama pull llama3.2:3b
```

This downloads the local AI model.

You can test it with:

```powershell
ollama run llama3.2:3b
```

Ask:

```text
Hello, who are you?
```

To exit the model, press Ctrl+C.

## STEP 3 — Open this project in VS Code

Open the `UniMate_AI` folder.

Then open:

**Terminal → New Terminal**

Run:

```powershell
python -m venv venv
```

Activate:

```powershell
.\venv\Scripts\Activate.ps1
```

Install Python packages:

```powershell
python -m pip install -r requirements.txt
```

## STEP 4 — Run the chatbot

```powershell
python -m streamlit run app.py
```

The browser should open at:

```text
http://localhost:8501
```

## Easy Windows option

After the first setup, double-click:

```text
run.bat
```

## If PowerShell blocks activation

Use:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```

Then:

```powershell
.\venv\Scripts\Activate.ps1
```

## If Ollama is offline

Make sure the Ollama Windows app is installed/running, then test:

```powershell
ollama list
```

The app uses:

```text
http://localhost:11434/api/chat
```

## Project presentation points

You can explain:

1. **Frontend:** Streamlit
2. **Backend:** Python
3. **Local AI Runtime:** Ollama
4. **LLM:** Llama 3.2 3B
5. **Communication:** HTTP/REST API on localhost
6. **Authentication:** No paid API key
7. **Privacy:** Prompts are processed locally by the installed model
8. **Languages:** English, Urdu and Roman Urdu can be used

## Customization

Change the assistant behavior in `app.py` inside `SYSTEM_PROMPT`.

You can also add:
- university FAQ documents
- PDF question answering
- student login
- database
- admin dashboard
- voice input/output
- RAG using local embeddings
